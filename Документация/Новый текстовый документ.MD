Modeling workflow note — syringe test

Goal

Build a simple editable 3D syringe as geometry, not as an image.

Output format

OBJ + MTL was chosen because it is:

plain text;

easy to inspect and regenerate;

directly importable into Blender;

good for deterministic procedural geometry.

Modeling method used

The model was generated procedurally in Python and written directly to OBJ.
Blender was not required to create the geometry.

Geometry rules

Two top-level OBJ objects:

Syringe_Barrel_Assembly

Syringe_Plunger_Assembly

Every circular/cylindrical section uses exactly 32 radial segments.

Main barrel is hollow.

Plunger is separate and can be translated independently.

Units are treated approximately as millimeters.

Practical lesson

For repeated work, reusable procedural primitives are useful:

cylinder / tapered cylinder;

hollow tube;

annular flange;

box/prism;

copy/transform of finished parts.

This is the beginning of the tool/workflow documentation the user wants to preserve for future modeling tasks.
